# Bright-Coffee-Sales-Analysis
Analysis of Bright Coffee Shop sales data and performance

Bright Coffee Shop Sales Analysis
Overview
Bright Coffee Shop Sales Analysis is a data analytics project focused on understanding coffee shop sales performance using transaction data from 1 January 2023 to 30 June 2023. The project explores revenue trends, product performance, and sales patterns to identify meaningful business insights and potential opportunities for growth.

Project Process
•	Data Preparation: Used Microsoft Excel to review, clean, and prepare the dataset for analysis.
•	Data Analysis: Explored sales trends, revenue, product categories, and weekday versus weekend performance.
•	Dashboard Development: Used Power BI and Looker Studio to create visualizations, KPIs, and interactive dashboards for presenting key findings.
•	Planning and Design: Used Miro for project planning, Lovable for dashboard prototyping, and Canva for visual design.
•	Data Analytics: Included Databricks in the project's data analytics toolkit.
 
 Tools Used
•	Microsoft Excel – Data cleaning and preparation.
•	Power BI – Data visualization and dashboard development.
•	Looker Studio – Interactive reporting and dashboards.
•	Databricks – Data processing and analytics workflows.
•	Miro – Project planning and brainstorming.
•	Lovable – Dashboard interface design and prototyping.
•	Canva – Visual assets and presentation design.

Summary
This project demonstrates how data analytics and business intelligence tools can transform raw sales data into meaningful insights. The analysis supports a better understanding of revenue performance, product trends, and purchasing patterns, while the dashboards present findings in a clear and accessible way. The insights can help identify opportunities for promotions, product recommendations, and improved business decision-making.
